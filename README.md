# Wayfare AI Planner Frontend

This repository contains the frontend for Wayfare's AI assisted trip planning module.

The AI planner is used after the selected trip has passed the feasibility stage. Its job is to turn the feasible trip information into a more detailed travel plan.

## Highlights

- AI assisted trip planning interface
- Works with the Wayfare trip planning flow
- Connects to a separate AI backend
- React based frontend
- Separate from the main tourism application
- Designed to receive trip information from the feasibility stage

## Overview

Wayfare separates trip feasibility from AI planning.

The feasibility engine first checks whether the selected destinations can reasonably fit within the available time. Once that check is complete, this frontend provides the interface for generating and viewing the AI assisted itinerary.

Keeping the two parts separate makes it clear which decisions come from deterministic calculations and which parts are generated by the AI service.

##  Usage

Run the frontend and use the planning interface to send trip information to the AI backend.

The AI backend URL is configured through the environment variables provided with the project.

## Installation

```bash
git clone https://github.com/sihalgorithm-exe/wayfare-ai-frontend.git
cd wayfare-ai-frontend
npm install
npm run dev
```

Create `.env` from `.env.example` and configure the AI backend URL.
